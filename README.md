# Working Sets

RAPP paper, part 4 of Frame Chains → Living Holograms → Thought Contracts → Working Sets. Kody Wildfeuer, RapterBox LLC.
First public disclosure: 2026-11-19, under the title Shared Presents. Rewritten 2026-11-20. This repository keeps its original name so every published link keeps working; "Shared Presents" is now an alias of "Working Sets".

A chat remembers its agents. Treat an agent runtime as an operating system: an agent file is a program, a saved chat is the launcher that opens only the programs that ran in it, and comparing which programs ran on the next pass is a check that reading the replies cannot give.

- Paper: https://kody-w.github.io/shared-presents/paper.html
- Proof: https://kody-w.github.io/shared-presents/play/replay.html
- First version, as published 2026-11-19: https://kody-w.github.io/shared-presents/v1/paper.html
